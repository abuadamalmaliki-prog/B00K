# InvoiceBot

Simple invoicing for freelancers. Create an invoice in 30 seconds, send it, get paid.

## Quick Start

```bash
node server.js
# Open http://localhost:3000
```

## Features

- Dashboard with revenue tracking
- Create and manage invoices with line items
- Client management
- Tax calculation
- Invoice preview and PDF print/export
- Status tracking (draft, sent, paid, overdue)
- Settings for company info, currency, tax rate

## Tech Stack

- Zero-dependency Node.js server
- Vanilla HTML/CSS/JS (no framework, no build step)
- JSON file storage
- Stripe-ready payment integration
