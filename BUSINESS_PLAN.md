# InvoiceBot — Business Plan

## Company Overview
**InvoiceBot** is a lightweight invoicing SaaS for freelancers and solo consultants.
No bloat, no learning curve — create an invoice in 30 seconds, send it, get paid.

## Revenue Model
- **Starter (Free):** 3 invoices/month, basic templates
- **Pro ($19/month):** Unlimited invoices, PDF export, payment links, client portal, branding
- **Business ($39/month):** Multi-currency, recurring invoices, expense tracking, reports

## $5,000 Target
- 22 Pro subscribers = $5,016 ARR
- Or 11 Business subscribers = $5,148 ARR
- Target: Month 3–4 post-launch

## Startup Costs (Under $500)
| Item | Cost |
|------|------|
| Domain (invoicebot.app) | $12/yr |
| Hosting (Railway/Render) | $0–7/mo |
| Stripe fees | 2.9% + $0.30/txn |
| Email (Resend free tier) | $0 |
| **Total Year 1** | **~$100** |

## Go-to-Market
1. Launch on Product Hunt, Indie Hackers, HN Show
2. SEO: "free invoice generator", "freelance invoice template"
3. Content: "How to invoice clients as a freelancer" blog posts
4. Reddit/Twitter organic posts in freelance communities
5. Lifetime deal on AppSumo ($49 one-time) for initial traction

## Competitive Advantage
- No sign-up required to create first invoice (try-before-buy)
- Fastest time-to-invoice in the market (30 seconds)
- Clean, modern UI — no enterprise bloat
- Open source core builds trust

## Tech Stack
- Node.js server (zero dependencies)
- Vanilla HTML/CSS/JS frontend
- JSON file storage (upgradeable to PostgreSQL)
- Stripe for payments
- HTML-to-PDF for invoice export
