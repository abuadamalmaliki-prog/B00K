# Fakhruddin al-Razi V2 — a full reading of *al-Maṭālib al-ʿĀliya min al-ʿIlm al-Ilāhī*

Source: `source_al-Matalib_al-Aliya.md` (ed. Aḥmad Ḥijāzī al-Saqqā, Dār al-Kitāb al-ʿArabī, Beirut 1987; via al-Shāmila al-Dhahabiyya).
43,877 lines · ~3.16M characters · ~585k words · 9 volumes (ajzāʾ).

## Method (and honesty rules)

1. **Skeleton first** — `00_TOC.md` was produced by `grep` over the markdown headings. That is a map, not reading.
2. **Sequential reading** — the assistant reads the text itself, in order, in line-range chunks
   (via the file-reading tool, no skipping, no keyword sampling, no script summarising for it).
3. **Notes after every chunk** — `notes/volN.md` records, for each chunk: what Razi argues, the
   enumerated proofs/objections/replies, who he cites, and his own verdict, with line references.
4. **Ledger** — `READING_LEDGER.md` logs every line range as it is read. If a range is not in the
   ledger, it has not been read. Gaps, if any, will be stated, not hidden.
5. **Memory caveat** — the assistant's working context is periodically compressed. The durable
   "understanding" therefore lives in these notes; the final synthesis (`SYNTHESIS.md`) is built from
   them, and specific claims point back to line numbers so they can be checked against the text.
